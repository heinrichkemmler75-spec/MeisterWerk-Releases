# MeisterWerk

**MeisterWerk** ist ein systemunabhängiges Werkzeug zur Organisation und Unterstützung von Pen-&-Paper-Rollenspielkampagnen.

Es richtet sich an Spielleiterinnen und Spielleiter, die Kampagnen, NSC, Orte, Karten, Handouts, Plots, Sitzungen und die fortlaufende Chronik einer Spielwelt übersichtlich miteinander verknüpfen möchten.

MeisterWerk arbeitet lokal und benötigt für seine eigentlichen Kampagnenfunktionen weder einen Onlinedienst noch eine KI.

## Aktuelle Veröffentlichung

Dieses Repository enthält die **offiziellen stabilen Veröffentlichungen von MeisterWerk**.

Die jeweils aktuelle Version befindet sich unter **Releases**.

MeisterWerk wird für folgende Plattformen bereitgestellt:

- **Linux x86-64**
- **Windows x86-64**
- **Android**

Die Android-Version wird als signierte Release-APK bereitgestellt, damit zukünftige Versionen als Updates derselben Anwendung installiert werden können.

## Funktionsumfang

MeisterWerk umfasst unter anderem:

- Kampagnenverwaltung
- NSC-Werk
- OrtsWerk
- KartenWerk
- HandoutWerk
- PlotWerk
- Kampagnennetz
- Sitzungsverwaltung
- ChronikWerk
- Präsentations- und Beamerfunktionen
- Import und Export vollständiger Kampagnen

Die einzelnen Bereiche sind miteinander verknüpft, sodass beispielsweise NSC, Orte, Karten, Handouts, Plotpunkte und Ereignisse nicht nur getrennt verwaltet, sondern innerhalb der Kampagne miteinander in Beziehung gesetzt werden können.

## Beispielkampagnen

Für MeisterWerk stehen Beispielkampagnen verschiedener Rollenspielsysteme zur Verfügung. Sie dienen sowohl als Anschauungsmaterial als auch dazu, die Möglichkeiten der einzelnen Werke und Verknüpfungen praktisch zu zeigen.
