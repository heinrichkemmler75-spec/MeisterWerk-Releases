# MeisterWerk

MeisterWerk ist ein systemunabhängiges Werkzeug zur Organisation und Unterstützung von Rollenspielkampagnen.

Dieses Repository enthält öffentliche Test- und Release-Versionen von MeisterWerk.

## Aktueller Stand

MeisterWerk befindet sich derzeit in der öffentlichen Testphase.

Die startbaren Versionen für die unterstützten Plattformen sowie der jeweils zugehörige Quellstand befinden sich unter **Releases**.
